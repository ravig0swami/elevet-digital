# 🚀 Elevate Digital

A modern, responsive landing page for a digital marketing agency built with **HTML5, CSS3, and Vanilla JavaScript**. The project focuses on clean UI, smooth animations, responsive layouts, and an engaging user experience without using any frameworks.

## ✨ Features

- Responsive design for all devices
- Modern dark-themed UI with glassmorphism
- Animated hero section and smooth scroll effects
- Interactive pricing, testimonials, and contact form
- Real-time form validation

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Google Fonts

## 📂 Project Structure

```text
elevate-digital/

```

## 🚀 Getting Started

```bash
git clone https://github.com/ravig0swami/elevate-digital.git
cd elevate-digital
```

Open **index.html** in your browser or run a local server.
